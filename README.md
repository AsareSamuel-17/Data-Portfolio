# Data-Portfolio
Power BI sales analytics dashboard for Pizzman Oyarifa, featuring revenue tracking, customer insights, product performance, and operational KPIs.

Project Overview

This Power BI project analyzes sales performance data from Pizzman Oyarifa, providing actionable insights into revenue generation, customer ordering behavior, staff performance, and product popularity.

The dashboard was designed to transform raw restaurant transaction data into meaningful business intelligence that supports data-driven decision-making.

Business Objectives

The dashboard aims to answer key business questions:

How much revenue is the restaurant generating?
Which menu items contribute the most sales?
What ordering channels are customers using?
Which payment methods are most preferred?
How does sales performance vary over time?
Which staff members process the highest number of orders?
What is the average customer satisfaction rating?
